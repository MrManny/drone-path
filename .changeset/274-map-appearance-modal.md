Map appearance is now a modal dialog with a live preview of the export frame — the loaded recording or a bundled example flight — and grouped settings: map style as thumbnail tiles, a trail color swatch row with an explicit Style default, an Auto-fit zoom toggle with a zoom level slider and Frame padding, clickable HUD chips, and an opening & ending strip. The entry moved from File to View, and the player shortcuts pause while the dialog is open.
